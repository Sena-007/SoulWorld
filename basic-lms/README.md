# SoulWorld MVP

SoulWorld is a calm, personal archive app for books, places, and music.

## Repository Structure
- `frontend`: React Native (Expo) mobile app.
- `backend`: Firebase configuration and Cloud Functions.
- `docs`: product backlog, scope constraints, analytics schema, release checklist.

## Quick Start
1. Configure environment files from `.env.example` templates.
2. Install frontend dependencies: `cd frontend && npm install`.
3. Install functions dependencies: `cd backend/functions && npm install`.
4. Run the app: `cd frontend && npm run start`.
